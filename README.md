# Convertisseur TXT → Excel

Application web pour convertir des fichiers .txt en fichiers Excel (.xlsx).

## Fonctionnalités
- Glisser-déposer de multiples fichiers .txt
- Détection automatique du séparateur (#, ;, virgule, tabulation, |)
- Fusion de tous les fichiers dans une seule feuille Excel
- Colonne "Fichier source" pour tracer l'origine de chaque ligne
- Aperçu des données avant conversion
- Interface en français

## Déploiement sur Vercel
1. Décompressez ce dossier
2. Poussez-le vers un repo GitHub
3. Connectez le repo à Vercel (https://vercel.com)
4. Vercel détectera automatiquement Next.js et déploiera

## Déploiement local
npm install && npm run build && npm start
